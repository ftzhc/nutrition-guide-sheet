# 栄養指導シート作成ツール

福岡天神頭痛と肺のクリニックのスタッフ（医師・看護師・管理栄養士）が、栄養指導のときに使う道具です。
患者さんの病名を選び、身長・体重などを入れると、「あなたの食事のポイント」が A4 1枚にまとまり、印刷して患者さんにお渡しできます。

> **大事な注意**
> 画面に出る文章と数字は、すべて **下書き** です。公開して患者さんに渡す前に、医師・管理栄養士が `CHECKLIST.md` にそって確認してください。
> 数字は、日本の主な診療ガイドラインと「日本人の食事摂取基準」を参考にした一般的な値です。

## 目的

- 栄養指導の内容を、患者さんが持ち帰れる1枚の紙にまとめる
- 病名が重なったときに、同じことを何度も書かず、ぶつかる内容には「相談」の印をつける
- 患者さんの情報をどこにも残さない（保存も送信もしない）

## 対象の病名（複数選べます）

高血圧症、脂質異常症、2型糖尿病、高尿酸血症、鉄欠乏性貧血、低アルブミン血症

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | 道具の本体。これ1つで動きます（HTML・CSS・JavaScript を1ファイルにまとめています） |
| `CHECKLIST.md` | 医師・管理栄養士が公開前に確認するリスト |
| `README.md` | この説明 |

外部のライブラリやフォント、他のサイトへの通信は使っていません。サーバー、データベース、ログインもありません。

## 使い方

1. ブラウザで `index.html` を開きます（GitHub Pages で公開した URL、またはダウンロードしたファイルをダブルクリック）。
2. 左の「入力」で、病名にチェックを入れます（複数可）。
3. 腎臓の病気がある・透析中の方は、「腎臓の病気がある・透析中」にチェックを入れます。
4. 年齢・性別・身長・体重を入れます。
5. 身体活動量を選びます。
6. 鉄欠乏性貧血を選ぶと「月経がある」の欄が出るので、あてはまれば チェックします（鉄の推奨量が変わります）。
7. 「スタッフのひとこと」に、患者さんへの一言を書けます（印刷に載ります。空欄なら手書き用の線が印刷されます）。
8. 右のプレビューを確認し、上の「印刷する」を押します。印刷の画面で **A4・縦** を選んでください。「背景のグラフィック」をオンにすると、表の色がきれいに出ます（オフでも読めます）。
9. 印刷した紙の「お名前：＿＿＿」に、患者さんのお名前を手書きします。
10. 次の患者さんの前に「入力をすべて消す」を押します。

### 入力した内容について

- 入力した内容は、ブラウザの画面の中だけで使い、どこにも保存・送信しません。画面を閉じたり再読み込みすると消えます。
- 患者さんのお名前を入れる欄はありません。お名前は印刷後に手書きしてください。
- 検索サイトに載らない設定（`noindex`）にしていますが、URL を知っている人は誰でも開けます。患者さんの情報は含まれないので、道具そのものが見られても問題はありません。

### 動くブラウザ

パソコン・タブレットの Chrome、Edge、Safari（新しいもの）で動きます。印刷は Chrome か Edge がおすすめです。画面が狭いときは、プレビューが入力欄の下に表示されます。

## 画面に出る内容と計算（すべて「目安」です）

- **BMI**：体重(kg) ÷ 身長(m)²。日本肥満学会の区分（普通体重、肥満（1度）など）を表示します。
- **目標体重**：65歳未満は 身長(m)²×22、65歳以上は 身長(m)²×22〜25 の幅。
- **1日のエネルギー量**：目標体重 × 係数。係数は「ほとんど座っている」25〜30、「座る仕事が中心だが通勤や家事で動く」30〜35、「立ち仕事や力仕事が多い」35〜 kcal/kg。幅で表示し、50 kcal 単位に丸めます。
- **病名ごとの目安**：食塩、コレステロール、食物繊維、プリン体、水分、鉄、お酒、たんぱく質（低アルブミン血症）など。
- **大事なポイント**：優先順に最大5つ。
- **控えたい食品・とりたい食品**：各8つまで。
- **病名が重なったとき**：食塩・お酒・体重などの重なる項目は1つにまとめ、数字は厳しいほうを使います。ぶつかる項目（例：高尿酸血症＋低アルブミン血症のたんぱく質）には「相談」の印がつきます。
- **腎臓の病気・透析**：たんぱく質の目標量と、野菜・果物を増やす指導（カリウム）、水分の指導は出さず、「腎臓の病気があるため、たんぱく質・カリウム・水分の量は医師の指示に従ってください」を目立つように表示します。
- **印刷**：A4 縦 1枚に収まるように作っています。内容が少し多いときは自動で少し縮小（最大 0.9 倍まで）し、それでも入らないとき（病名が3つ以上のときなど）は2枚になります。
- 画面の下に「最終更新日」と「医師・管理栄養士確認：未／済」が出ます。確認が「未」のあいだは、印刷の下部にも小さく「（下書き・医師・管理栄養士確認：未）」と出ます。

## 文章や数字の直し方

文章・数字・食品リストは、すべて `index.html` の中の **1か所** にまとめてあります。
`index.html` を開き、`<script>` のすぐ下にある `const DATA = {` から `/* ===== データはここまで ===== */` までが、直す場所です。日本語のコメント（`//` や `/* */` のあとの文）を頼りに探してください。その下の「プログラム」の部分は、ふつうは直す必要がありません。

### GitHub のサイト上で直す手順

1. GitHub のリポジトリのページで `index.html` をクリックします。
2. 右上の鉛筆のマーク（Edit）をクリックします。
3. 直したい文章や数字を書きかえます。
4. 右上の緑のボタン「Commit changes...」を押し、何を直したかを短く書いて、もう一度「Commit changes」を押します。
5. GitHub Pages で公開していれば、数分で反映されます（ブラウザで再読み込みしてください）。

### よくある直し方の例

- **数字を変える**：`value: '1日 6g未満'` のように、`' '` の中の文字を書きかえます。
- **ポイントの文章を変える**：`title:`（見出し）と `body:`（説明）の `' '` の中を書きかえます。
- **食品を足す**：`take:`（とりたい食品）や `avoid:`（控えたい食品）の中に、次のような1行を足します。

  ```
  { key: 'dm_natto', priority: 50, text: '納豆（1日1パック）' },
  ```

  `key` は半角英字で、他の行と重ならない名前にします。`priority` は大きいほど上に出ます。行の最後のカンマ `,` を忘れないでください。
- **順番を変える**：`priority` の数字を変えます（大きいほど先に出ます）。
- **腎臓のときに出さない**：その行に `kidneyHide: true,` を足します。腎臓のときだけ別の文にしたいなら `kidneyBody:`（ポイント）、`kidneyText:`（食品）、`kidneyValue:`（1日の目安）を足します。
- **「相談」の印をつける**：その行に `consult: true,` を足します。
- **ポイントや食品の数を変える**：`maxPoints: 5`、`maxFoods: 8` の数字を変えます。
- **最終更新日と確認の状態**：`lastUpdated: '2026-11-05'` と `reviewStatus: '未'` を書きかえます。確認が終わったら `'済'` にしてください。
- **クリニック名や題名**：`clinicName`、`sheetTitle`、`footerMessage` を書きかえます。

### 書きかえるときの注意

- 文字は `' '`（半角のシングルクォート）で囲みます。文の中で `'` は使わず、「 」を使ってください。
- `{ }` や `[ ]`、行の最後の `,` を消さないでください。1つ消えるだけで画面が真っ白になります。
- 全角スペースや全角の記号を、`' '` の外に入れないでください。
- 直したあとは、ブラウザで `index.html` を開き直して、画面がきちんと出るか、下の「動作確認の例」のように入力して確かめてください。もし真っ白になったら、直した場所をもう一度見直すか、GitHub の「History」から前の版に戻してください。

## GitHub Pages で公開する手順

GitHub Pages は、GitHub にあるファイルをそのままウェブページとして公開するしくみです。無料で使えます。

1. このリポジトリ（`ftzhc/nutrition-guide-sheet`）のページを開きます。
2. 上の「Settings」をクリックします。
3. 左のメニューから「Pages」をクリックします。
4. 「Build and deployment」の「Source」で「Deploy from a branch」を選びます。
5. 「Branch」で `main` を選び、フォルダは `/ (root)` のまま「Save」を押します。
6. 数分待ってページを再読み込みすると、「Your site is live at https://ftzhc.github.io/nutrition-guide-sheet/」のように URL が出ます。この URL をスタッフで共有してください（ブックマークしておくと便利です）。

注意

- 無料プランでは、リポジトリが **Public**（公開）でないと GitHub Pages は使えません。Public にすると、ファイルの中身は誰でも見られますが、患者さんの情報は含まれていません。
- 作業用のブランチ（`claude/...` で始まる名前）で作ったものは、`main` に取り込んでから公開します（GitHub の「Pull requests」→「New pull request」→「Merge」）。
- 公開をやめたいときは、同じ「Pages」の画面で「Source」を「None」にします。

## 動作確認の例

次の3つの例を入力して、画面と印刷プレビュー（「印刷する」を押して出る画面）が下のとおりになることを確認してください。日付は、その日の日付が自動で入ります。

### 例1：高血圧症＋2型糖尿病の60代男性

入力：高血圧症・2型糖尿病にチェック、62歳、男性、170 cm、75 kg、「座る仕事が中心だが、通勤や家事で動く」、ひとこと「まず「汁物は1日1杯」から始めてみましょう。次回、体重と血圧の記録を見せてください。」

| 確認するところ | 期待する表示 |
| --- | --- |
| 対象の病名 | 高血圧症、2型糖尿病 |
| 今のBMI | 26.0　肥満（1度） |
| 目標体重 | 63.6 kg（身長(m)² × 22、65歳未満） |
| 1日のエネルギー | 約 1,900〜2,250 kcal（目標体重 63.6kg × 30〜35 kcal） |
| 食塩 | 1日 6g未満（高血圧の値が優先され、糖尿病の 7.5g は出ない） |
| 食物繊維 | 1日 20g以上 |
| お酒 | 1日 ビール中びん1本か日本酒1合まで |
| 大事なポイント | 5つ。1番が「食塩は1日 6g未満に」。2型糖尿病の「主食・主菜・副菜」「1日3食」「野菜から先に」、BMI 25以上なので「体重を少し減らしましょう（約2.3〜3.8kg）」 |
| 食品の表 | 控えたい食品 8つ、とりたい食品 8つ（甘い飲み物、漬物、野菜、魚 など） |
| スタッフのひとこと | 入力した文がそのまま出る |
| 印刷 | A4 縦 1枚に収まる |

### そのほかの確認

- 「入力をすべて消す」を押すと、チェック・数字・ひとことが全部消え、プレビューが「病名を選ぶと…」の表示に戻る。
- 脂質異常症＋鉄欠乏性貧血では、とりたい食品からレバーが消え、「レバーは控え、赤身の肉・あさり・大豆製品で鉄をとる【相談】」のポイントが出る。
- 2型糖尿病（または脂質異常症）＋低アルブミン血症では、エネルギーの行が2つ並び、両方に「相談」の印がつく。
- 病名を3つ以上選ぶと、印刷が2枚になることがあります。
